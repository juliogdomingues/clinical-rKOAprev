# CLAUDE.md

## Coding guidelines

For any task involving writing, reviewing, or refactoring code, use the
`karpathy-guidelines` skill before starting.

The skill ships with the `andrej-karpathy-skills` plugin, registered for this
repo in `.claude/settings.json`, so sessions pick it up automatically. If it is
missing, run `/plugin install andrej-karpathy-skills@karpathy-skills`.
